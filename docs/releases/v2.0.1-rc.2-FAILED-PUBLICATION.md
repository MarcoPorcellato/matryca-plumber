creation stopped before either public destination was written.

does not make it a public release artifact.

## Destination and recovery boundary

At terminal review on 2026-08-31, GitHub Releases returned `404` for
`v2.0.1-rc.2` and PyPI returned `404` for `matryca-plumber==2.0.1rc2`. The signed tag
and failed run remain preserved. The unchanged workflow must not be rerun: it would
retain the missing repository binding.

Recovery requires the tested workflow correction to reach protected `main`, followed
by a fresh versioned candidate, new signed tag, new destination preflight, new artifact
build and attestations, and separate publication authority. RC2 evidence does not
qualify that later candidate and cannot be transferred to Gate B or stable promotion.
