## Upgrade

```bash
uvx matryca-plumber@2.0.0-alpha.2 --version   # expect 2.0.0-alpha.2 (PyPI 2.0.0a2)
# From 2.0.0a1 on the same vault — no schema migration; shadow.sqlite cache is reused.
export MATRYCA_SHADOW_DB_ENABLED=true   # optional — experimental
uvx matryca-plumber@2.0.0-alpha.2 plumber start --foreground
```

**Default-off guarantee:** unset `MATRYCA_SHADOW_DB_ENABLED` preserves v1.14.x BM25 + parser subtree behavior.
