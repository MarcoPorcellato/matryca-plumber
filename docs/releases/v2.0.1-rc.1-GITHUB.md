## Summary

`v2.0.1-rc.1` was published as the maintenance candidate after stable `v2.0.0`. It adds a
bounded canonical `journal_day` read and provider-free evidence tooling while
preserving the stable Shadow, Strict Read Only, Markdown-authority, parser, write-plane,
and fallback contracts.

Stable `v2.0.0` remains the default recommendation. This prerelease is available for
explicit evaluation and does not represent publication or qualification of final
`v2.0.1`.

This record is bound only to release commit
`48eae93b1152c9fe7d1f19d63de3f781b686932e` and its public distributions. Later
repository revisions are outside its evidence boundary and require independent
classification and qualification.
