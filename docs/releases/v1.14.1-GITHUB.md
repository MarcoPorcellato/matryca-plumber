# GitHub Release — v1.14.1 (copy-paste)

**Title:** v1.14.1 - Map-of-Content Generation Wired Up

**Tag:** `v1.14.1`

---

## Summary

**Small maintenance release.** `moc_page.py` (Map-of-Content index page generation) has existed on disk since the Logseq-superpowers work but had no `mutate_graph` / CLI action pointing to it — the agent could never call it. This release wires it up and closes matching doc gaps: `SYSTEM_PROMPT.md` already documented `inject_query` / `unify_tags` with worked examples, but `llms.txt` (the zero-shot LLM-facing guide) did not.

**Why upgrade:** agents can now generate a namespace-scoped Map-of-Content page (`[[wikilinks]]` grouped by sub-namespace) via `mutate_graph action=generate_moc` or `matryca mutate generate_moc`, dry-run by default. No breaking changes; purely additive.

Operators should upgrade with `uvx matryca-plumber` ≥ **1.14.1**. Point LLM hosts at **`llms.txt` v1.14.1**.

## Highlights

| Area | Change |
|------|--------|
| `mutate_graph` / CLI | New `action=generate_moc` — namespace stem → `[[wikilink]]` index page, `dry_run` default true |
| `llms.txt` | New zero-shot examples H (`inject_query`), I (`unify_tags`), J (`generate_moc`) |

## Added

- `handle_mutate_generate_moc` dispatch handler (`src/agent/dispatch_mutate_handlers.py`), backed by the existing `write_moc_page` (`src/graph/moc_page.py`).
- `MutateGraphAction` gains `"generate_moc"`; CLI `mutate` subcommand accepts it.
- Tests covering missing-target error and dry-run preview (`tests/test_graph_dispatch_mutate.py`).

## Docs

- `SYSTEM_PROMPT.md` § `mutate_graph` documents `action=generate_moc` with a worked JSON example.
- `llms.txt` zero-shot examples H/I/J mirror `SYSTEM_PROMPT.md` coverage for `inject_query`, `unify_tags`, and `generate_moc`.

## Upgrade

```bash
uvx matryca-plumber --version   # expect 1.14.1
uvx matryca-plumber --help      # resolves latest wheel from PyPI
```
