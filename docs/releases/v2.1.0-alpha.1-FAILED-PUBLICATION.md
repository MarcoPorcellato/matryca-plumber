## Cause and evidence limits

The workflow attempted to override RUNNER_TOOL_CACHE, a reserved runner variable. The runner substitutes its own context when executing steps. The requested action-private path printed in the step environment therefore did not establish the effective shell value. The retained log and exact runner source support the existing-default-cache guard as the first failure; the individual failed builtin and its argument were not traced directly.

Both publisher bootstrap blocks and the eight not-yet-dispatched public-input jobs shared this acquisition defect. It is not an observed failure of the producer, parser, installed package or public-byte semantics. Earlier [exact-source qualification](https://github.com/MarcoPorcellato/matryca-plumber/actions/runs/39113970216) does not substitute for public bytes.
