## Summary

**Minor release:** backward-compatible internal refactor for v2.0 preparation. Splits `maintenance_daemon` ([#58](https://github.com/MarcoPorcellato/matryca-plumber/issues/58)) and `graph_dispatch` ([#59](https://github.com/MarcoPorcellato/matryca-plumber/issues/59)) into focused modules, introduces **`GraphReadPort`** / `MarkdownGraphRepository` (v2 Phase 1), and ships community onboarding docs. **No intentional PyPI CLI/MCP break** for vault operators.

**Visitor entry point:** [`docs/roadmaps/ROADMAP_V2_PREPARATION.md`](../roadmaps/ROADMAP_V2_PREPARATION.md) · Epic [#20](https://github.com/MarcoPorcellato/matryca-plumber/issues/20).

Operators upgrade with `uvx matryca-plumber` ≥ **1.13.0**.
