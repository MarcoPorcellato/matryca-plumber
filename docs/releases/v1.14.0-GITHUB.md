# GitHub Release — v1.14.0 (copy-paste)

**Title:** v1.14.0 - Catalog Write-Safety & Leaf-Module Dependency Direction

**Tag:** `v1.14.0`

---

## Summary

**Reliability minor** after the [2026-07-16 deep code audit](../AUDIT_REPORT_2026-07-16.md): closes catalog resurrection bugs, teaches the file watcher about renames, relocates four deferred import cycles to their true lowest-layer modules, and lands Clean Code Tier F good-first closures (`#170`–`#173`).

**Why upgrade:** operators running a busy daemon co-editing a vault with humans benefit from correct `MasterCatalog` merge-save semantics (remove→upsert no longer drops the row; corrupt JSON is quarantined instead of silently emptied) and rename-aware watching. Contributors get CI guards so `src/graph/` cannot quietly import `src/rag/`, plus shared `env_parse` instead of one-off helpers. No MCP/CLI surface changes required.

Operators should upgrade with `uvx matryca-plumber` ≥ **1.14.0**. Point LLM hosts at **`llms.txt` v1.14.0**.

## Fixed

- **`MasterCatalog` write-safety** — remove-then-upsert no longer lost on save; corrupt/non-dict JSON logged and quarantined; `prune_missing_pages` records removals; case-insensitive lookup uses a cached casefold index.
- **File watcher** — rename events handled; debounce consolidated onto one scheduler thread.
- **Leaf-module dependency direction** — `DaemonState` / phase-2 metrics, AST cache, LLM URL canonicalization, and `resolve_existing_page_title` live at the correct layer (one Tana cycle left intentional for monkeypatch compatibility).

## Added

- CI graph→rag import forbid (+ `generational_cache.py` allowlist for follow-up).
- Parametrized env clamp-contract tests for link-verify and generational-cache thresholds.
- Public audit report documenting F1–F11 findings and remediation.

## Changed

- Shared `env_parse.env_bool` / `env_int` adoption in concurrency probe and agent config modules.
- Frontend npm Dependabot group bumps; `astral-sh/setup-uv` Actions bumps.
- Docs / diary / CONTRIBUTING Mermaid lifecycle diagrams aligned to post-audit state.

```bash
uvx matryca-plumber --version   # expect 1.14.0

```
