## Summary

Matryca Plumber v2.0.0 is the stable Shadow read-path release for Logseq OG.
It gives agents fast, structured reads through a daemon-owned external Shadow DB
while keeping human-readable Logseq Markdown as the system of record.

The release completes the transition from the opt-in, graph-local beta path to a
default-on, health-gated external derived cache. Strict Read Only is compatible with
Shadow acceleration: graph-local mutation is blocked while validated cache maintenance
remains available outside the graph.

## What is included

- **External Shadow DB by default** — SQLite FTS5 and recursive-CTE subtree reads use
  a disposable per-graph cache outside `LOGSEQ_GRAPH_PATH`.
- **Strict Read Only protection** — `MATRYCA_READ_ONLY=true` blocks every graph-local
  mutation while preserving validated external derived-cache writes.
- **Markdown authority** — Shadow never becomes the source of truth and never replaces
  the parser-aware OCC-protected write plane.
- **Fail-closed routing** — disabled, bootstrapping, stale, schema-mismatched, or
  unhealthy Shadow states fall back to Markdown-backed BM25 reads.
- **Stable parser baseline** — `logseq-matryca-parser` 1.7.1.
- **Governed outcome and retrieval contracts** — provenance-bound, content-free
  evidence surfaces for later benchmark and memory work without enabling those future
  capabilities in the stable runtime.

## Deliberately out of scope

The following remain future work for v2.1.0 or later:

- biological memory recall, decay, and consolidation as a shipped runtime path;
- native Logseq DB writes or Safe-Sync through internal SQLite;
- content-aware Tana merge;
- proactive adaptive runtime behavior.

## Upgrade

```bash
uv tool install matryca-plumber==2.0.0
```

For an existing installation:

```bash
uv tool upgrade matryca-plumber
```

Before enabling graph writes or maintenance, work on a clone of the graph and review
the [Shadow DB operator contract](../knowledge/architecture/shadow-db.md). Operators
who need the legacy discovery path can set:

```bash
MATRYCA_SHADOW_DB_ENABLED=false
```
