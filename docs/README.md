# Matryca Plumber documentation orientation

Matryca Plumber is authoritative for its documentation. Start with the
[maintained knowledge bundle](knowledge/index.md), then consult the
[system architecture](ARCHITECTURE.md), [contributor path](FIRST_CONTRIBUTION.md)
and [release process](RELEASE_PROCESS.md). Historical and generated material is
classified by the maintained bundle rather than treated as current guidance.
